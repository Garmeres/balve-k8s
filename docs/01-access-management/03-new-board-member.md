# New board member

A new board member needs a Balve (Nextcloud) account, a garmeres email, and a Strapi account.

1. [Create a Balve (Nextcloud) account](09-manage-balve-users.md#add-a-new-user) for them
2. [Add them to the **Board members** group](09-manage-balve-users.md#add-a-user-to-a-group). This gives them access to the **Garmeres board's internal files** shared folder, in addition to the **Shared files for all Balve users** folder that all users can access
3. [Create a garmeres.com email address](10-manage-email-users.md#create-a-new-email) for them (e.g. `fornavn@garmeres.com`)
4. [Add them to the **meile@garmeres.com** forwarding group](10-manage-email-users.md#add-a-user-to-a-forwarding-group). All board members should be in this group — it is the shared board mailing address
5. Consider whether they should also receive mail sent to **admin@garmeres.com**. This group is for the chairman, deputy chairman, technical manager, and others with elevated roles. If they should be in it, [add them to that group](10-manage-email-users.md#add-a-user-to-a-forwarding-group) the same way
6. [Invite them to Strapi](11-manage-strapi-users.md#invite-a-new-user) with the **Editor** role. This lets them edit all content on the Garmeres website
