# Manage Balve users

## Add a new user

1. Log in to [balve.garmeres.com](https://balve.garmeres.com) as an admin
2. Go to **Settings** → **Users**
3. Click **New user**
4. Fill in username and display name
5. Leave the password empty
6. Click **Send welcome email**
7. Click **Add a new user**

The person will receive an email with a link to set their password.

---

## Add a user to a group

Use this when someone joins the board or becomes an admin.

1. Log in to [balve.garmeres.com](https://balve.garmeres.com) as an admin
2. Go to **Settings** → **Users**
3. Find the user
4. Click the **Groups** column for that user
5. Select the group to add them to (e.g. **Styret** for board members, **admin** for admins)

---

## Remove a user from a group

Use this when someone leaves the board or should no longer be an admin.

1. Log in to [balve.garmeres.com](https://balve.garmeres.com) as an admin
2. Go to **Settings** → **Users**
3. Find the user
4. Click the **Groups** column for that user
5. Click the **x** next to the group to remove them from it

---

## Remove a user

Use this if a user should no longer have access at all.

1. Log in to [balve.garmeres.com](https://balve.garmeres.com) as an admin
2. Go to **Settings** → **Users**
3. Find the user
4. Click the **...** menu on the right side of their row
5. Click **Delete user**

> **Note:** This permanently deletes the user and all their personal files. If you only want to revoke access temporarily, disable the user instead (same menu → **Disable user**).

---

## Reset a user's 2FA

If a user has lost access to their authenticator app and can't log in:

1. Log in to [balve.garmeres.com](https://balve.garmeres.com) as an admin
2. Go to **Settings** → **Users**
3. Find the user
4. Click the **...** menu on the right side of their row
5. Click **Wipe all devices** under Two-Factor Authentication

The user will be prompted to set up 2FA again on their next login.

---

## Share a password with a user

Use this to securely share a password or secret with someone who has a Nextcloud account.

1. Log in to [balve.garmeres.com](https://balve.garmeres.com)
2. Open the **Passwords** app from the top menu
3. Find or create the password entry you want to share
4. Click the **Share** icon on the entry
5. Type the user's name and select them
6. Choose whether the other person can only view the password or also edit it, then confirm

The password will appear in the other user's Passwords app.
