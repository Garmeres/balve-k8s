# Manage Hetzner users

Hetzner Cloud is where the servers are hosted. Only the technical manager needs access here.

Users are managed in the project at [console.hetzner.cloud](https://console.hetzner.cloud).

---

## Add a user

Typically when there is a new technical manager.

1. Ask the person to create a Hetzner account at [console.hetzner.cloud](https://console.hetzner.cloud)
2. Log in to [console.hetzner.cloud](https://console.hetzner.cloud)
3. Open the project **balve**
4. Go to **Members** in the left sidebar
5. Click **Add member**
6. Enter the person's email address
7. Set the role to **Admin**
8. Click **Add**

The person will receive an email invitation.

---

## Remove a user

Typically for an outgoing technical manager.

1. Log in to [console.hetzner.cloud](https://console.hetzner.cloud)
2. Open the project **balve**
3. Go to **Members** in the left sidebar
4. Find the person and click **Remove**
