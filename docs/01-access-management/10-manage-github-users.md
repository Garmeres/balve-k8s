# Manage GitHub users

The code repositories are hosted on GitHub under the [Garmeres](https://github.com/Garmeres) organization. Only the technical manager needs access here.

---

## Add a user

1. Ask the person to create a GitHub account at [github.com](https://github.com)
2. Go to [github.com/orgs/Garmeres/people](https://github.com/orgs/Garmeres/people)
3. Click **Invite member**
4. Enter the person's GitHub username or email
5. Send the invitation

The person will need to accept the invitation.

---

## Add a user to a team

Typically when there is a new technical manager, or a new person wanting to collaborate on the balve platform.

The technical manager should be in the **admins** team. Anyone else should be in **developers**.

1. Go to [github.com/orgs/Garmeres/teams](https://github.com/orgs/Garmeres/teams)
2. Click the team you want to add the person to
3. Click **Members**
4. Click **Add a member**
5. Enter the person's GitHub username or email
6. Select the person and confirm

---

## Remove a user from a team

Typically for an outgoing technical manager or outgoing collaborators.

1. Go to [github.com/orgs/Garmeres/teams](https://github.com/orgs/Garmeres/teams)
2. Click the team you want to remove the person from
3. Click **Members**
4. Find the person
5. Click the dropdown next to their name and select **Remove from team**

---

## Remove a user

1. Go to [github.com/orgs/Garmeres/people](https://github.com/orgs/Garmeres/people)
2. Find the person
3. Click the gear icon next to their name
4. Select **Remove from organization**
